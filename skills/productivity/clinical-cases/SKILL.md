# Clinical Cases & Exam Prep

## Quick start

1. Share the reference material (PDF, book excerpt, notes, or paste text directly)
2. Paste the question, test, or clinical case
3. The skill will answer using the provided material as primary source

## How to provide material

- **Paste text directly** — copy the relevant chapter or section into the chat
- **Upload a file** — attach PDFs, Word docs, or images of textbook pages
- **Multiple sources** — you can share several materials; specify which one to prioritize if they conflict

## Answering questions

For each question:

1. **Identify the type**: multiple choice, open-ended, clinical case, true/false
2. **Locate the relevant content** in the provided material
3. **Give the answer** clearly and directly
4. **Explain the reasoning** with a brief justification tied to the source
5. **Flag uncertainty** if the answer isn't covered in the provided material

## Clinical cases

For clinical cases, follow this structure:

1. **Patient summary** — key data: age, sex, chief complaint, vitals
2. **Relevant findings** — physical exam, labs, imaging mentioned in the case
3. **Differential diagnosis** — list possibilities ranked by likelihood
4. **Most likely diagnosis** — with justification from the case data
5. **Management plan** — treatment, follow-up, referrals per the source material

## Working through a full test

If given a complete test:

- Answer all questions sequentially
- Mark each answer clearly: **Q1. (answer)** — reason
- At the end, provide a summary of topics covered and any weak spots to review

## Source discipline

- Base answers on the provided material first
- If the material doesn't cover a question, say so explicitly and answer from general medical/nursing knowledge, flagging it as "not in provided material"
- Never fabricate citations or page numbers
